# Mr.arsadik

Personal landing page for **Abdullah Sadik**.

## Purpose

A focused personal page that communicates personality and selected work without turning into a long portfolio. The primary CTA is a structured WhatsApp call request.

## Booking flow

Visitors provide:

- Call type
- Preferred date
- Preferred time
- Name
- Context / description

The page then opens WhatsApp to **+90 536 201 5920** with a pre-filled appointment request.

## Stack

Plain HTML, CSS and JavaScript. No framework or build step.

## Local preview

Open `index.html` directly, or serve the folder with any static HTTP server.

## Deployment

Works as a static site on GitHub Pages, Cloudflare Pages, Netlify or Vercel.
